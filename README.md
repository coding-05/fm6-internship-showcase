# FM6 Education — Frontend Modernization (Internship Project)

> Internship project at **Fondation Mohammed VI de Promotion des Œuvres Sociales de l'Éducation-Formation**
> *Note: The original source code is proprietary and confidential. This repo showcases my contributions through screenshots and sanitized code snippets.*

## 🎯 Project Overview

Redesigned and modernized the internal **SGA (Système de Gestion des Adhérents)** web application used by the foundation's staff to manage ~544,000 education sector members.

**Tech stack:** Next.js, React, TypeScript, Material-UI, Redux Toolkit Query, Spring Boot (API)

## 🛠️ My Contributions

### 🎨 UI/UX Modernization
- Redesigned the **sidebar navigation** with smooth animations, active state indicators, and a glassmorphism user card
- Rebuilt the **home page dashboard** with modern card layouts, hover effects, and entry animations
- Ensured **visual consistency** across all pages

### 🌗 Dark / Light Mode
- Added a **theme toggle** in the header
- Implemented **localStorage persistence** so the user's preference survives navigation and reloads
- Synchronized **sidebar colors** with the global theme
- Fixed color contrast issues across all components

### 📊 Real Data Dashboard
- Connected the redesigned dashboard to **existing backend REST APIs**
- Mapped API responses to UI cards (adherents, pending requests, users)
- Removed placeholder data, ensuring **100% real DB values**

### 📤 Excel Export Feature
- Added a **universal export button** to all data tables
- Implemented **per-row export** — one click to export a single record
- Built a **hover-expand animation** for a compact, elegant UI
